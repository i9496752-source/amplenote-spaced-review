# Next Steps

1. Follow `amplenote-account-publish.md` to create the Amplenote plugin note from `plugin-note.md`.
2. Install the note as a plugin from Account Settings -> Plugins.
3. Paste `sample-cards.md` into a sample note and run the install smoke test.
4. Record the usage and code overview videos using `video-outline.md`.
5. Add the two video URLs to the plugin note, replacing `<USAGE_VIDEO_URL>` and `<CODE_OVERVIEW_VIDEO_URL>`.
6. Publish the note and submit it to the Amplenote Plugin Directory from the note token publish options.
7. Save the public plugin URL and any Plugin Directory listing URL.
8. Prepare the PayPal invoice using `paypal-invoice-checklist.md`.
9. Fill `claim-email-template.md` with plugin URL, video URLs, current bounty amount, and PayPal invoice details.
10. Send the claim only after the plugin is published or Amplenote explicitly accepts the public note URL for review.
