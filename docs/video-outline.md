# Video Outline

## Usage Video

1. Show a note containing Q/A blocks and a Markdown card table.
2. Run `Create review deck`.
3. Run `Add review cards from this note`.
4. Open the generated deck note and show due dates, intervals, ease, reps, and lapses.
5. Run `Review due cards`.
6. Mark one card Again, one Good, and one Easy.
7. Reopen the deck note and show changed due dates.

## Code Overview Video

1. `plugin.js`: parser, deck renderer, merge logic, scheduling, and Amplenote actions.
2. `test/core.test.js`: unit coverage for parsing, deck persistence, prompt handling, and deck creation.
3. `scripts/build.mjs`: creates the paste-ready Amplenote code block.
4. `plugin-note.md`: metadata table and code-block placeholder.
5. `docs/release-checklist.md`: acceptance and publication checklist.
