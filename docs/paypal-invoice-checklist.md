Use this only for the private claim email or PayPal invoice. Do not publish PayPal details in the plugin note.

## Invoice Fields

- Recipient: Amplenote / Alloy.dev team
- Recipient email: `hello@amplenote.com`
- Optional support contact: `support@amplenote.com`
- Item name: `Spaced Review Amplenote plugin bounty`
- Item description: `Implementation, tests, documentation, public GitHub repository, Plugin Directory publication, usage video, and code overview video for the Amplenote Spaced repetition plugin bounty.`
- Amount: confirm the current amount on https://www.amplenote.com/bounty_plugins before sending
- Currency: USD
- Quantity: 1
- Terms: Due on receipt
- PayPal receiving address: `<PAYPAL_EMAIL>`
- Public plugin URL: `<AMPLENOTE_PLUGIN_URL>`
- Repository URL: `https://github.com/i9496752-source/amplenote-spaced-review`
- Usage video URL: `<USAGE_VIDEO_URL>`
- Code overview video URL: `<CODE_OVERVIEW_VIDEO_URL>`

## Before Sending

- Confirm the bounty is still listed and the amount has not changed.
- Confirm the plugin is published to the Amplenote Plugin Directory or Amplenote has explicitly accepted the public note URL for review.
- Confirm the PayPal receiving address is correct.
- Keep a PDF copy or invoice number for the claim email.
